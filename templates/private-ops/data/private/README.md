# Private literature state

This directory is owned by the pinned DeepGeno.watch automation. It may contain source evidence, candidate decisions, Draft Summaries, Published Summaries, approval provenance, sealed releases, delivery receipts, and review bodies.

Keep the repository private. Review changes through the Gate 1 and Gate 2 pull requests generated by the workflows; do not publish or copy this state into the public engine repository.

Synthesis request records are an execution safety boundary. Do not edit their prepared, armed, dispatching, ambiguous, or completed states by hand. Follow the public operations runbook for timestamp-guarded reconciliation after inspecting provider history.

Controlled activation manifests belong under `data/private/activation/` and must never be copied into the public engine. The controlled-scan compiler validates the private manifest against the generated Gate 1 body before the curator updates or merges that review.
